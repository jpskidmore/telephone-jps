# jps Telephone 2.1.6 (build 158)

Interface refinements, 7 October 2026. Apple silicon, macOS 15.6+.

## Main window

The compact dial bar and recent-call row use consistent alignment and spacing.
The More menu uses **Clear Call History…** and no longer duplicates the visible
history button with Show/Hide Call History commands. The button still expands
and collapses history; existing redial, deletion and clear-history confirmation
behaviour is retained.

## Settings

Every Settings pane uses the Accounts pane's window size, so changing sections
does not make the window jump in size. The icon rail and native Close control
remain available, and the General, Sound and Network forms are placed within
the same content area.

The top-level **Network** section applies to all accounts. The account-specific
tab is labelled **Connection**, distinguishing it from the app-wide section.
All existing options, account restrictions and network save/cancel/discard
behaviour are retained.

The interface remains UK English only, with system colours and materials for
Light and Dark appearance. Calling and recording behaviour is unchanged.

## Local build and verification

This update is built and checked locally on the Mac. The generated
BUILD-VERIFICATION.md records the exact source revision, local toolchain and
checks that actually completed. No cloud build is used for this update.

The application is an ad-hoc signed, unnotarised local test build. Live SIP,
real audio devices, VoiceOver and full operating-system coverage remain manual
acceptance checks. Quit the previous edition before opening the updated app;
its existing application identity retains settings and credentials.
