# jps Telephone 2.1.7 (build 159)

Availability colours, 7 October 2026. Apple silicon, macOS 15.6+.

The compact main window shows online availability in system green and offline
availability in system red. Existing status symbols, tooltips, accessible labels,
registration actions and window geometry are retained. System colours adapt to
Light and Dark appearance.

Settings retains its current window size and controls.

The update is built and verified locally. BUILD-VERIFICATION.md records the
source revision and checks that actually completed; no cloud build is used.
Calling, recording, account options and history behaviour are unchanged.

This is an ad-hoc signed, unnotarised local test build. Live SIP, real audio
devices and VoiceOver remain manual acceptance checks. Quit the previous edition
before opening the updated app; its existing identity retains settings and
credentials.
