# jps Telephone 3.8 (167)

This point release includes all pushed application changes since 3.7: shared asynchronous Keychain reads with stale-result and credential lifecycle guards; compact call windows matching the standard dialler footprint; and actor-built immutable Contacts snapshots for dialler and transfer completion.

Apple silicon, macOS 15.6 or later. Ad-hoc signed and unnotarised, consistent with previous releases. Existing accounts, routing and user data are preserved. Actual provider, physical audio, OS permission/grant and proficient VoiceOver acceptance remain pending in issue #62. Synthetic verification does not replace those checks.

Prepared on 4 November 2026 from pushed main 04c75fe. Build, test, package and publication results are recorded separately. No local installation or cloud workflow is requested.
