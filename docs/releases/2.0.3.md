# jps Telephone 2.0.3 (build 154)

Version 2.0.3 fixes final recording files disappearing when a call ends.

## Root cause

The SIP recorder could report that it had closed its WAV tracks just before
the finalized WAV headers became visible to the background encoder.
AudioToolbox briefly returned `kAudioFileInvalidFileError`; the converter then
correctly removed its unusable destination placeholder, making it appear that
the recording itself had been deleted.

## Fix

The background encoder now retries transient incomplete-WAV errors for up to
two seconds. Once the SIP recorder's finalized headers are visible, normal
stereo MP3, Ogg, or Source conversion continues and the final file remains in
the selected recordings folder.

The failed 2.0.2 attempts retained their private left/right recovery tracks;
the audio was not discarded.
