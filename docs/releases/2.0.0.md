# jps Telephone 2.0.0 (build 151)

This is the security-hardened release of the blue jps Telephone edition for Apple silicon Macs running macOS 15.6 or later.

## Highlights

- Optional automatic recording of every connected call.
- Local party on the left channel and remote party on the right.
- OGG for the smallest files, MP3 for compatibility, or Source WAV with no additional lossy encoding.
- User-selected recording destination.
- Collision-safe private files, private temporary tracks, and background finalization.
- PJSIP 2.17, LibreSSL 4.3.2, and Opus 1.6.1.
- Removal of the unnecessary disabled-library-validation entitlement.
- Focused normal, asynchronous, and sanitizer-enabled recording tests.

- **`jps Telephone 2.0.0 build 151 secure recording.zip`** — tested macOS application.
- **`jps Telephone 2.0.0 build 151 secure recording source.zip`** — complete source snapshot, artwork, tests, prebuilt dependencies, and upstream source archives.

- **`jps Telephone 2.0.0 build 151 SHA256SUMS.txt`** — SHA-256 checksums.

## Installation note

The app is ad-hoc signed and has passed deep signature verification, but it is not Apple-notarized. After extracting it and moving it to **Applications**, Control-click it and choose **Open** if macOS asks for confirmation.

## Recording notice

Automatic recording is off by default. Only enable it when recording is lawful and everyone whose consent is required has consented.
