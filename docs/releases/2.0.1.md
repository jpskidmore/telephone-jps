# jps Telephone 2.0.1 (build 152)

Version 2.0.1 fixes the immediate launch crash in the downloadable 2.0.0 app.

## Root cause

The 2.0.0 bundle used the hardened runtime and correctly passed deep static
signature verification. However, its ad-hoc signature had no Apple Team ID.
macOS library validation therefore refused to map the bundled
`Domain.framework` and terminated the app before `main()`.

## Fix

The downloadable build now receives an explicitly ad-hoc-only
library-validation exception after every nested framework and XPC service has
been signed. The app sandbox and hardened runtime remain enabled. Normal
project entitlements retain library validation for future Developer ID builds.

The release includes the corrected Apple-silicon app, complete source, a
verification report, and SHA-256 checksums.
