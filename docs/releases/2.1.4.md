# jps Telephone 2.1.4 (build 156)

Settings repair and visible material composition, 5 October 2026. Apple silicon, macOS 15.6+.

## What failed and what changed

Version 2.1.3 could open a blank Settings window. Populating the new native
sidebar synchronously selected its first row while the detail view was still
being assembled. That selection attempted to create constraints with a missing
detail anchor, interrupting window initialization.

The complete content hierarchy now exists before the sidebar is populated.
Initial selection is guarded until setup finishes. General, Accounts, Sound and
Network retain their existing controls, bindings, actions and Network save
prompts. The window is consistently titled Settings.

The white window underlay also made the glass look flat. Settings and call
windows now have a native frosted backdrop that blends the environment behind
them, with regular Liquid Glass for navigation and call controls. Settings
extends that backdrop beneath its titlebar while preserving a safe area for
the original forms. Reduce Transparency retains an opaque system background,
and material changes preserve keyboard focus and text selection.

A regression now loads the production Preferences nib and complete window
controller, checking the populated sidebar and attached General form. A native
local reproduction independently confirmed the old exception and corrected
initialization. The release pipeline retains candidate app/source archives for
local interface inspection before publication. It also verifies the app ZIP
after extraction without Finder/resource metadata.

This retains the two interface improvements and bounded reliability fixes from
[2.1.3](https://github.com/jpskidmore/telephone-jps/blob/v2.1.4/docs/releases/2.1.3.md).
See [interface guidance and acceptance checks](https://github.com/jpskidmore/telephone-jps/blob/v2.1.4/docs/LIQUID_GLASS.md).

## Verification and local testing

The generated BUILD-VERIFICATION.md identifies the exact source commit and
successful automated checks. Local interface acceptance checks all four Settings
sections in the compiled app before publishing the corrected release.

This is an ad-hoc signed, unnotarized local test build. Live SIP, actual audio
devices, VoiceOver and full OS/appearance coverage still require manual testing.

Quit the previous edition, unzip the app archive and open jps Telephone.app.
The bundle identity remains uk.jpsit.telephone and keeps existing settings and
credentials. Keep the installed copy until local call/audio acceptance passes.
