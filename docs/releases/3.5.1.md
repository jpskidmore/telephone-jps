# jps Telephone 3.5.1 (163) — Guided routes crash repair

Fix the crash when choosing More → Guided routes… from the compact main window.
The window controller previously sent its own action to an unspecified target;
AppKit selected that same controller again in the responder chain. Repeated
synchronous dispatch overflowed the stack. macOS reports for 3.5/162 recorded a stack
protection fault and repeated NSApplication action-dispatch frames.

The action now targets the application delegate explicitly and preserves the
menu sender. Existing Settings opening and Dial plan selection still belong to
AppController. The private More-menu construction is factored for a native
regression without displaying a blocking popup.

The new native regression exercises the generated menu item and real
NSApplication dispatch. A scoped observer preserves native dispatch and records
its actual target, requiring the production action to supply the application
delegate explicitly, preserve its sender and open Settings/Dial plan once.
Missing ownership must not redispatch to an unspecified target. Window-focus
fixtures could not reliably recreate the collision in the isolated test host;
those failed diagnostics are retained. The observed 3.5 crash reports provide
the before-fix stack-overflow evidence. The earlier 3.5 suite did not cover this
menu forwarding boundary.

Only the shared action implementation, its regression and version/documentation
change. Country/area expansion, route selection, call functions, compact layout,
account history and stored data are unchanged. All work is local on main, with
[skip ci] commits and a private repository. v3.5, v3.0 and v2.1.8 remain immutable.

Fresh local validation passed **665 test cases, zero failures**: 300 isolated
app cases and 365 framework cases. Read [test proof](3.5.1-tests.json) and
[validation scope](../VALIDATION.md). The separate 170 routing cases remain
historical 3.5 unchanged-source evidence, not a fresh hotfix run.

Release packaging, installation and publication remain in progress; completed
evidence will be recorded after those steps finish.
