# jps Telephone 3.9.2 (175)

Contacts access is now requested automatically once during normal startup when macOS has not yet recorded a choice. After permission is allowed, contact names become available to dialler completion and caller/history matching. Existing grants, denials and restrictions are respected; passive activation/refresh does not repeatedly prompt. Settings → General retains Allow Contacts, retry and System Settings recovery.

Six named synthetic Contacts regressions are now mandatory native validation/release checks, including first-use access through history matching and dialler publication, existing permission choices, failure/retry and revocation. Signed release checks also require the Contacts entitlement and permission explanation. The owner accepted preceding local build 174; that confirmation is separate from this release's automated validation and does not imply comprehensive real-address-book/denial/rollback testing.

All earlier 3.9.1 Keychain fixes and 3.9 features remain. Apple silicon; macOS 15.6 or later. Ad-hoc signed and unnotarised. The release process does not install the app, access real Contacts/credentials, change privacy grants, place calls or inspect live history/recordings. #62 remains closed not planned.

Read BUILD-VERIFICATION.md for exact source and fresh local checks; SHA256SUMS.txt covers downloadable files. All prior release tags/assets remain unchanged.
