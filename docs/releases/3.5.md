# jps Telephone 3.5 — Guided routes

Version 3.5 / build 162 adds one compact dialler, a combined call/missed-call history and configurable outgoing routing for all SIP accounts.

- Expand local and national numbers using configurable country and area defaults before routing.
- Assign Mobile, Landline, International, Premium, Other and Service routes; add precise active prefixes or Block exceptions with longest-prefix matching.
- Re-evaluate the current plan for Contacts, links, Services, history callbacks and call-card redial.
- Derive history badges from account names while retaining UUID identities and original account attribution.
- Require an explicit emergency provider, preserve short/service/SIP syntax, and report unavailable chosen accounts without silent fallback.
- Preserve the accepted compact UK-English interface, uniform Settings size, native close controls, Light/Dark and green Online/red Offline.

See [the user and maintenance guide](../DIAL_PLANS.md), [offline numbering coverage](../DIAL_PLAN_NUMBERING.md) and [local validation](../VALIDATION.md). The private repository stays on main; every build is local and pushed commits use [skip ci]. Historical v2.1.8 and v3.0 tags and assets remain unchanged.

All four current local suites passed 664 test cases with zero failures. Separately, the production dial-plan harness passed 170 cases; fresh native URI/lifecycle/callback, history, audio, recording and dependency checks passed. Native synthetic Light/Dark renderings retain the compact bounds.
