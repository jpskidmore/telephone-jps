# jps Telephone 2.1.3 (build 155)

Local test release, 5 October 2026. Marketing version increases from 2.0.3 to
2.1.3; the build number increases from 154 to 155. Apple silicon, macOS 15.6+.

## Interface

Two substantial presentation changes preserve existing calling and settings
actions:

1. Incoming, active and ended call screens use a clearer caller/status hierarchy,
   larger labeled native controls and a grouped control surface. Native Liquid
   Glass is limited to controls on macOS 26+, with a native fallback on macOS 15.
2. Settings uses native sidebar navigation for the existing General, Accounts,
   Sound and Network sections, with clearer selection and keyboard access.

See [Liquid Glass implementation and Apple guidance](../LIQUID_GLASS.md) for
availability, accessibility behavior and visual acceptance checks.

## Reliability

The release includes the previously unreleased audio-failure recovery and
recording-lifetime cleanup. It also includes bounded Foundation and receipt
robustness fixes from the [bug review](../BUG_REVIEW_2.1.3.md).

SIP features, account credentials, recording formats, recording consent defaults,
audio retry behavior and call-history storage retain their existing purpose.

## Build and verification

The GitHub test-release workflow builds the exact main commit using the checked-in
arm64 dependencies, runs isolated native regression harnesses and the four
XCTest suites, and then signs and verifies the Release app. It publishes an app
ZIP, complete source ZIP, release notes, SHA-256 checksums and an exact-commit
`BUILD-VERIFICATION.md` report only after those checks pass. That generated report
is the evidence for the specific downloadable build.

This is an **ad-hoc signed, unnotarized test build**. Test on this Mac before using
it for important calls. Live SIP, actual microphones/headsets, dark/light
appearance, VoiceOver and Reduce Transparency acceptance remain manual checks.

## Try it locally

Unzip `jps-Telephone-2.1.3-arm64.zip` and open **jps Telephone.app**. Keep the
current installed app until the new build passes your call/audio checks. The
bundle identity remains `uk.jpsit.telephone`, so the app uses the same saved
settings and credentials. Quit the existing edition before opening this build.

The build targets macOS 15.6+. Liquid Glass itself requires macOS 26+; the older
system presentation remains available on macOS 15. If macOS blocks first launch,
use its normal **Open Anyway** flow in Privacy & Security after reviewing the
download and checksums.
